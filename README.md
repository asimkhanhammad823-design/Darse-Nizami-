# Dars-e-Nizami Audio Platform

A complete, **zero-cost** audio learning platform for Dars-e-Nizami studies:
students browse Darja → Kitab → Lecture, stream protected audio with a live
"Safa" (page) indicator, and admins manage all content and student access
codes from a simple panel.

## Architecture (3 parts, all free tier)

| Part | Folder | Tech | Where it runs | Cost |
|---|---|---|---|---|
| **Backend API** | [`worker/`](worker/) | Cloudflare Workers + D1 + Backblaze B2 | Cloudflare free tier, always on | $0 |
| **Admin panel** | [`admin/`](admin/) | FastAPI (Python) | Your own PC (`localhost`), only when adding content | $0 |
| **Student app** | [`app/`](app/) | Flutter (Android) | Students' phones | $0 |

Audio files live in a **private** Backblaze B2 bucket (10 GB free) and are
only ever served through short-lived signed URLs issued by the Worker to
logged-in users — there is no public link to any audio file.

## Setup order

1. **`worker/`** — deploy the API first (see [worker/README.md](worker/README.md)).
2. **`admin/`** — run the panel locally, log in with your admin access code,
   create Darjas/Books/Lectures and student access codes
   (see [admin/README.md](admin/README.md)).
3. **`app/`** — build the Android app and hand it to students along with
   their access codes (see [app/README.md](app/README.md)).

## Key features

- **Access-code login** — no emails/passwords; you hand each student a short
  code generated by the admin panel's Users page. Revoking a code locks that
  student out immediately (their session token also expires after 30 days).
- **Protected streaming** — audio streams via signed URLs that expire after
  10 minutes; the app refreshes them transparently. `FLAG_SECURE` blocks
  screenshots/screen recording; nothing is downloaded to disk.
- **Live page display** — admins set "time → page" markers with a
  mark-current-time button; the app shows the current Safa number as the
  audio plays.
- **Resume playback** — the app remembers where each student left off in
  every lecture (stored on-device only).
- **Self-cleaning storage** — deleting a lecture (or a whole book/darja)
  also deletes the audio files from B2, so the free 10 GB never fills up
  with orphans.
- **Background playback** — lock-screen controls, speed control
  (1x/1.25x/1.5x/2x), 15s skip buttons.

## Free-tier limits to keep in mind

- **Cloudflare Workers:** 100,000 requests/day — far above what a class of
  students will generate.
- **Cloudflare D1:** 5 GB storage, 5M reads/day on the free plan.
- **Backblaze B2:** 10 GB storage free; free download bandwidth equals ~3×
  your stored data per month. If you have 5 GB of audio, that's ~15 GB of
  streaming per month free. If a large class streams heavily, this is the
  first limit you'd hit — the fix is keeping bitrates modest (64 kbps mono
  speech ≈ 28 MB/hour, so 10 GB ≈ 350 hours of lectures).

## Ideas for later (not yet implemented)

- Rate-limit `/login` (e.g. Cloudflare WAF free rules) against code guessing.
- Per-device binding of access codes to stop code sharing.
- Server-side listening progress so a student's position follows them across
  devices.
- Compress/normalize audio on upload (e.g. re-encode to 64 kbps Opus) to
  stretch the free storage and bandwidth further.
